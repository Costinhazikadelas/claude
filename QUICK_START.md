# 🚀 Quick Start - Telegram CRM

Tudo automatizado! Apenas 2 passos:

## Windows

### Passo 1: Setup (primeira vez apenas)
Duplo clique em `setup.bat` e aguarde terminar ✅

### Passo 2: Rodar
Duplo clique em `start.bat` e a aplicação abre automaticamente 🎉

---

## macOS / Linux

### Passo 1: Setup (primeira vez apenas)
```bash
chmod +x setup.sh
./setup.sh
```

### Passo 2: Rodar
```bash
./start.sh
```

Abre automaticamente em http://localhost:3000 🎉

---

## ✅ Quando vir a tela de login:

1. **Número de telefone**: `+55 11 99999-9999` (ajuste seu número)
2. **Aguarde**: Telegram vai enviar um código
3. **Digite o código** que recebeu
4. **Pronto!** Sistema importa seu histórico automaticamente ✨

---

## 🆘 Problemas?

### "Python não encontrado"
→ Instale: https://www.python.org/downloads/

### "Node.js não encontrado"
→ Instale: https://nodejs.org/

### Página não abre
→ Aguarde 5 segundos e acesse http://localhost:3000 manualmente

### Outro erro?
→ Verifique o terminal que abriu com a mensagem de erro
